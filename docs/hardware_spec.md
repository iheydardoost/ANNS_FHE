# Hardware Specification — Vitis HLS-First Architecture

> ANNS_FHE CKKS Accelerator — All compute kernels as synthesizable HLS C++.

---

## 1. Design Philosophy

| Principle | Decision |
|-----------|----------|
| **Compute datapath** | 100% Vitis HLS C++ |
| **SystemVerilog** | Top-level testbench and Vivado block-design integration only |
| **AXI interfaces** | Auto-generated by `#pragma HLS INTERFACE` |
| **Verification** | C simulation → C/RTL co-simulation → Vivado synthesis |
| **Optimization** | Functional correctness FIRST, then add pragmas iteratively |
| **Existing code reuse** | Adapt OpenFHE-style C++ into HLS-synthesizable C++ |

## 4. Module Specifications (HLS C++ Functions)

### 4.1 `mod_mul_barrett` — Modular Multiply (Inline)

```cpp
// mod_arith.h — FULLY INLINED, not a separate kernel
inline uint64_t mod_mul(uint64_t a, uint64_t b, uint64_t q,
                        uint64_t m, uint32_t k) {
    #pragma HLS INLINE
    ap_uint<128> prod = ap_uint<128>(a) * ap_uint<128>(b);
    ap_uint<128> est  = (prod * ap_uint<128>(m)) >> k;
    uint64_t r = (uint64_t)(prod - est * ap_uint<128>(q));
    if (r >= q) r -= q;
    if (r >= q) r -= q;  // at most 2 corrections for Barrett
    return r;
}

inline uint64_t mod_add(uint64_t a, uint64_t b, uint64_t q) {
    #pragma HLS INLINE
    uint64_t s = a + b;
    return (s >= q) ? s - q : s;
}

inline uint64_t mod_sub(uint64_t a, uint64_t b, uint64_t q) {
    #pragma HLS INLINE
    return (a >= b) ? a - b : a + q - b;
}
```

**Key HLS detail**: Using `ap_uint<128>` for the 128-bit intermediate product.
Vitis HLS maps this to DSP48E2 chains automatically.

| Property | Value |
|----------|-------|
| Implementation | `#pragma HLS INLINE` — no separate module |
| Latency | HLS-scheduled (target: II=1 with pipeline) |
| DSPs | ~4–8 per `mod_mul` instance (auto-inferred from `ap_uint<128>` multiply) |
| Dependencies | `ap_uint` from `ap_int.h` |

### 4.2 `ntt_kernel` — N-Point NTT/INTT

```cpp
// ntt.h / ntt.cpp
void ntt_single_limb(
    uint64_t poly[N],             // in-place transform
    const uint64_t twiddles[N/2], // precomputed twiddle factors
    uint64_t q, uint64_t m, uint32_t k,
    bool inverse                  // true=INTT, false=NTT
);
```

#### HLS Optimization Strategy

```cpp
void ntt_single_limb(uint64_t poly[N], const uint64_t tw[N/2],
                     uint64_t q, uint64_t bm, uint32_t bk, bool inv) {
    #pragma HLS INLINE off

    // On-chip buffer for the polynomial
    uint64_t buf[N];
    #pragma HLS BIND_STORAGE variable=buf type=ram_2p impl=uram
    #pragma HLS ARRAY_PARTITION variable=buf cyclic factor=NUM_BFLY*2

    // Twiddle factor buffer
    uint64_t tw_buf[N/2];
    #pragma HLS BIND_STORAGE variable=tw_buf type=rom_np impl=bram

    // Burst-load polynomial from argument
    load_poly: for (int i = 0; i < N; i++) {
        #pragma HLS PIPELINE II=1
        buf[i] = poly[i];
    }

    // Burst-load twiddles
    load_tw: for (int i = 0; i < N/2; i++) {
        #pragma HLS PIPELINE II=1
        tw_buf[i] = tw[i];
    }

    // NTT butterfly stages
    int len = inv ? 1 : N/2;
    ntt_stages: for (int stage = 0; stage < LOG2_N; stage++) {
        #pragma HLS LOOP_TRIPCOUNT min=LOG2_N max=LOG2_N
        int half = inv ? (1 << stage) : (N >> (stage + 1));
        int step = 2 * half;

        ntt_groups: for (int start = 0; start < N; start += step) {
            #pragma HLS LOOP_TRIPCOUNT min=1 max=N/2
            ntt_bflies: for (int j = 0; j < half; j++) {
                #pragma HLS PIPELINE II=1
                #pragma HLS UNROLL factor=NUM_BFLY
                int idx_a = start + j;
                int idx_b = start + j + half;
                uint64_t w = tw_buf[/* twiddle index */];
                uint64_t u = buf[idx_a];
                uint64_t v = mod_mul(buf[idx_b], w, q, bm, bk);
                buf[idx_a] = mod_add(u, v, q);
                buf[idx_b] = mod_sub(u, v, q);
            }
        }
    }

    // INTT: multiply by N^{-1} mod q
    if (inv) {
        scale: for (int i = 0; i < N; i++) {
            #pragma HLS PIPELINE II=1
            buf[i] = mod_mul(buf[i], /* n_inv */, q, bm, bk);
        }
    }

    // Burst-store result
    store_poly: for (int i = 0; i < N; i++) {
        #pragma HLS PIPELINE II=1
        poly[i] = buf[i];
    }
}
```

**Multi-limb wrapper**:
```cpp
void ntt_all_limbs(uint64_t poly[MAX_LIMBS * N],
                   const uint64_t twiddles[MAX_LIMBS * N/2],
                   const uint64_t primes[MAX_LIMBS], ...,
                   int active_limbs, bool inverse) {
    for (int l = 0; l < active_limbs; l++) {
        #pragma HLS LOOP_TRIPCOUNT min=1 max=MAX_LIMBS
        ntt_single_limb(&poly[l * N], &twiddles[l * N/2],
                        primes[l], ..., inverse);
    }
}
```

| Property | Value |
|----------|-------|
| On-chip storage | `uint64_t buf[N]` → URAM, 128 KB per limb |
| Parallelism | `UNROLL factor=NUM_BFLY` → 8 butterflies/cycle |
| Twiddle storage | `tw_buf[N/2]` → BRAM ROM, 64 KB per prime |
| Estimated II | 1 cycle per butterfly (target) |
| Cycles/limb | $N/2 \times \log_2(N) / \text{NUM\_BFLY} \approx 14,336$ |
| Total (11 limbs) | ~158,000 cycles per full NTT |

### 4.3 `poly_arith` — Polynomial Add/Sub/Mul

```cpp
// poly_arith.cpp
void poly_add_all(uint64_t dst[], const uint64_t a[], const uint64_t b[],
                  const uint64_t primes[], int active_limbs) {
    for (int l = 0; l < active_limbs; l++) {
        #pragma HLS LOOP_TRIPCOUNT min=1 max=MAX_LIMBS
        for (int j = 0; j < N; j++) {
            #pragma HLS PIPELINE II=1
            dst[l*N + j] = mod_add(a[l*N + j], b[l*N + j], primes[l]);
        }
    }
}

// poly_mul: NTT(a), NTT(b) if needed, coeff-wise mul, INTT
void poly_mul_ntt_domain(uint64_t dst[], const uint64_t a[], const uint64_t b[],
                         const uint64_t primes[], ..., int active_limbs) {
    // Assuming a, b already in NTT domain
    for (int l = 0; l < active_limbs; l++) {
        #pragma HLS LOOP_TRIPCOUNT min=1 max=MAX_LIMBS
        for (int j = 0; j < N; j++) {
            #pragma HLS PIPELINE II=1
            dst[l*N + j] = mod_mul(a[l*N + j], b[l*N + j],
                                   primes[l], bm[l], bk[l]);
        }
    }
}
```

### 4.4 `automorphism_kernel` — Galois Automorphism

```cpp
// automorphism.cpp
void automorphism(uint64_t dst[], const uint64_t src[],
                  uint32_t galois_elt, const uint64_t primes[],
                  int active_limbs) {
    // Precompute permutation table (small, done once per rotation amount)
    int perm[N];
    bool negate[N];
    #pragma HLS ARRAY_PARTITION variable=perm complete  // if N small enough, else cyclic

    compute_perm: for (int i = 0; i < N; i++) {
        #pragma HLS PIPELINE II=1
        uint32_t idx = ((uint64_t)i * galois_elt) % (2 * N);
        negate[i] = (idx >= (uint32_t)N);
        perm[i] = idx % N;
    }

    // Apply permutation per limb
    for (int l = 0; l < active_limbs; l++) {
        #pragma HLS LOOP_TRIPCOUNT min=1 max=MAX_LIMBS
        for (int i = 0; i < N; i++) {
            #pragma HLS PIPELINE II=1
            uint64_t val = src[l*N + perm[i]];
            dst[l*N + i] = negate[i] ? (primes[l] - val) : val;
        }
    }
}
```

| Property | Value |
|----------|-------|
| Latency | $N \times L$ cycles (streaming) |
| DSPs | 0 |
| BRAM/URAM | Permutation table `perm[N]` in BRAM |

### 4.5 `key_switch_kernel` — Key Switching

This is the most complex and performance-critical function.

```cpp
// key_switch.cpp
void key_switch(
    uint64_t ct1_poly[MAX_LIMBS * N],       // Input c_1 polynomial
    uint64_t result_0[MAX_LIMBS * N],        // Output correction for c_0
    uint64_t result_1[MAX_LIMBS * N],        // Output correction for c_1
    const uint64_t* evk_gmem,                // Eval key in global memory
    const uint64_t twiddles[MAX_LIMBS * N/2],
    const uint64_t primes[MAX_LIMBS],
    const uint64_t barrett_m[MAX_LIMBS],
    const uint32_t barrett_k[MAX_LIMBS],
    const uint64_t n_inv[MAX_LIMBS],
    int active_limbs, int dnum
) {
    #pragma HLS INLINE off

    // Local accumulators for result polynomials
    uint64_t acc_0[MAX_LIMBS * N];
    uint64_t acc_1[MAX_LIMBS * N];
    #pragma HLS BIND_STORAGE variable=acc_0 type=ram_2p impl=uram
    #pragma HLS BIND_STORAGE variable=acc_1 type=ram_2p impl=uram

    // Zero accumulators
    zero_acc: for (int i = 0; i < active_limbs * N; i++) {
        #pragma HLS PIPELINE II=1
        acc_0[i] = 0;
        acc_1[i] = 0;
    }

    // Process each digit
    digit_loop: for (int d = 0; d < dnum; d++) {
        #pragma HLS LOOP_TRIPCOUNT min=1 max=4

        // 1. Extract digit d from ct1_poly (RNS decomposition)
        uint64_t digit[MAX_LIMBS * N];
        #pragma HLS BIND_STORAGE variable=digit type=ram_2p impl=uram
        extract_digit(ct1_poly, digit, d, dnum, active_limbs, primes);

        // 2. Forward NTT each limb of the digit
        ntt_all_limbs(digit, twiddles, primes, barrett_m, barrett_k,
                      active_limbs, /*inverse=*/false);

        // 3. Stream eval key component from global memory, MAC into accumulators
        //    evk[d] = (evk_b, evk_a), each is a polynomial of active_limbs × N
        int evk_component_words = 2 * active_limbs * N;
        int evk_offset = d * evk_component_words;

        // Load evk[d].b and multiply-accumulate with digit
        for (int l = 0; l < active_limbs; l++) {
            #pragma HLS LOOP_TRIPCOUNT min=1 max=MAX_LIMBS
            for (int j = 0; j < N; j++) {
                #pragma HLS PIPELINE II=1
                uint64_t evk_b_val = evk_gmem[evk_offset + l*N + j];
                acc_0[l*N + j] = mod_add(acc_0[l*N + j],
                    mod_mul(digit[l*N + j], evk_b_val,
                            primes[l], barrett_m[l], barrett_k[l]),
                    primes[l]);
            }
        }

        // Load evk[d].a and multiply-accumulate
        int evk_a_off = evk_offset + active_limbs * N;
        for (int l = 0; l < active_limbs; l++) {
            #pragma HLS LOOP_TRIPCOUNT min=1 max=MAX_LIMBS
            for (int j = 0; j < N; j++) {
                #pragma HLS PIPELINE II=1
                uint64_t evk_a_val = evk_gmem[evk_a_off + l*N + j];
                acc_1[l*N + j] = mod_add(acc_1[l*N + j],
                    mod_mul(digit[l*N + j], evk_a_val,
                            primes[l], barrett_m[l], barrett_k[l]),
                    primes[l]);
            }
        }
    }

    // 4. Inverse NTT the accumulators
    ntt_all_limbs(acc_0, twiddles, primes, barrett_m, barrett_k,
                  n_inv, active_limbs, /*inverse=*/true);
    ntt_all_limbs(acc_1, twiddles, primes, barrett_m, barrett_k,
                  n_inv, active_limbs, /*inverse=*/true);

    // 5. Copy to output
    for (int i = 0; i < active_limbs * N; i++) {
        #pragma HLS PIPELINE II=1
        result_0[i] = acc_0[i];
        result_1[i] = acc_1[i];
    }
}
```

| Property | Value |
|----------|-------|
| On-chip memory | `acc_0`, `acc_1`, `digit` → 3 × 1.4 MB URAM = 4.2 MB |
| Global memory reads | $2 \times d_{\text{num}} \times L \times N \times 8$ bytes per call = ~8.6 MB |
| Latency estimate | $d_{\text{num}} \times (L \times \text{NTT} + 2 \times L \times N) + 2 \times L \times \text{INTT}$ |
| At dnum=3, L=11 | ~1.1M cycles |
| DSPs | 4–8 (reused `mod_mul` instances via HLS scheduling) |

### 4.6 `rescale_kernel` — CKKS Rescale

```cpp
void rescale(uint64_t ct[2 * MAX_LIMBS * N],
             const uint64_t primes[], const uint64_t barrett_m[],
             const uint32_t barrett_k[], int active_limbs) {
    #pragma HLS INLINE off
    int last = active_limbs - 1;
    uint64_t q_last = primes[last];

    // For each of the two polynomials in the ciphertext
    for (int p = 0; p < 2; p++) {
        int base = p * MAX_LIMBS * N;
        // For each remaining limb, subtract last limb contribution and divide
        for (int l = 0; l < last; l++) {
            #pragma HLS LOOP_TRIPCOUNT min=1 max=MAX_LIMBS
            // q_last_inv_mod_ql = modular inverse of q_last mod q_l (precomputed)
            for (int j = 0; j < N; j++) {
                #pragma HLS PIPELINE II=1
                uint64_t last_val = ct[base + last*N + j];
                uint64_t cur_val  = ct[base + l*N + j];
                // Subtract last limb (mod switch)
                uint64_t diff = mod_sub(cur_val, last_val % primes[l], primes[l]);
                // Divide by q_last: multiply by q_last^{-1} mod q_l
                ct[base + l*N + j] = mod_mul(diff, /* q_last_inv_mod[l] */,
                                             primes[l], barrett_m[l], barrett_k[l]);
            }
        }
    }
    // active_limbs decremented by caller
}
```

## 5. Operation Dispatch (Top-Level Switch)

```cpp
extern "C" void fhe_accel_top(/* ... all ports ... */) {
    // Pragma declarations for interfaces (see §3.2)

    switch (op_code) {
        case OP_NTT:
            // Load one limb from poly_gmem, NTT in-place, store back
            burst_load(poly_gmem, src_a_offset, local_buf, N);
            ntt_single_limb(local_buf, &twiddle_buf[prime_idx * N/2],
                           rns_primes[prime_idx], ...);
            burst_store(poly_gmem, dst_offset, local_buf, N);
            break;

        case OP_POLY_ADD_ALL:
            burst_load(poly_gmem, src_a_offset, buf_a, active_limbs * N);
            burst_load(poly_gmem, src_b_offset, buf_b, active_limbs * N);
            poly_add_all(buf_dst, buf_a, buf_b, rns_primes, active_limbs);
            burst_store(poly_gmem, dst_offset, buf_dst, active_limbs * N);
            break;

        case OP_KEY_SWITCH:
            burst_load(poly_gmem, src_a_offset, ct1_buf, active_limbs * N);
            key_switch(ct1_buf, ks_result_0, ks_result_1,
                      &key_gmem[evk_offset], ...);
            burst_store(poly_gmem, dst_offset, ks_result_0, active_limbs * N);
            burst_store(poly_gmem, dst_offset + active_limbs * N,
                       ks_result_1, active_limbs * N);
            break;

        case OP_AUTOMORPH:
            burst_load(poly_gmem, src_a_offset, buf_a, active_limbs * N);
            automorphism(buf_dst, buf_a, galois_elt, rns_primes, active_limbs);
            burst_store(poly_gmem, dst_offset, buf_dst, active_limbs * N);
            break;

        case OP_RESCALE:
            burst_load(poly_gmem, src_a_offset, ct_buf, 2 * active_limbs * N);
            rescale(ct_buf, rns_primes, barrett_m, barrett_k, active_limbs);
            burst_store(poly_gmem, dst_offset, ct_buf, 2 * (active_limbs-1) * N);
            break;

        // ... other operations
    }
}
```
